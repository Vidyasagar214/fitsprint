# Phase 3 — Profiles & workout core (MVP)

**Status:** ✅ Delivered  
**Depends on:** Phase 1 foundation, Phase 2 auth

## Scope

- Profile save (name, bio, goals, height, weight, BMI)
- Training focus preferences
- Settings (units, notifications) persisted
- Workout library from `workout_templates`
- Start + complete workout sessions → updates dashboard activity
- Live dashboard stats, weekly chart, recent workouts
- Progress page charts from `daily_activity_snapshots`

## Out of scope (later phases)

- Per-set logging (`workout_session_sets`)
- Nutrition meal persistence (Phase 5)
- Custom user-created exercises
- Stripe / automatic premium upgrade
